01 · ORIENTATION

What is VEYA?

In plain terms first: VEYA is a system where an AI doesn't just talk to you — it sits at the center of a small ecosystem, with tools, extensions and even physical hardware it can call on to actually get things done.

“Think of VEYA as an operating ecosystem for an intelligent assistant.”

03 · INTELLIGENCE

AI + Agent Architecture

Four different terms get used loosely in this space. VEYA treats them as distinct layers, not synonyms.

AI Model

The raw reasoning engine. It predicts and generates — it has no memory of its own and no ability to act on the world.

AI Agent

A model wrapped with a role, tools and boundaries — it can plan and take a bounded set of actions.

Agent System

Multiple agents coordinating on a shared task, each with a specialty.

VEYA

The ecosystem that hosts, supervises and constrains the whole agent system.

The model supplies intelligence. The agent supplies controlled behavior — tools, permissions, and a defined job description.

Plugin Lifecycle
Discovery → Installation → Activation → Permission grant → Sandboxed execution → Versioning & updates → Core communication via the Event Bus → Deactivation / removal. A plugin never talks to the rest of the system directly — every call passes back through the core.

05 · EXTENSIBILITY

Plugins vs. Mods

Related, but not the same thing.

Plugin

Adds a capability or tool to VEYA.

Mod

Changes, extends or transforms how VEYA itself behaves or looks.

  • Add GitHub integration
  • Add Arduino control

Mod examples

  • Change personality

07 · HARDWARE

Software ↔ Hardware Bridge

The AI never touches raw hardware directly. Everything routes through a controlled abstraction layer.

AI / Agent
↓
VEYA Core
↓
Hardware Abstraction Layer
↓
Device Driver / Protocol
↓
MCU / SBC
↓
Physical Hardware

Why bother with a middle layer? Because it lets the AI ask for an outcome ("show this text") without ever needing to know which exact chip or driver makes that happen — and it gives the security layer a single choke point to police.
